# frontend/

React + Vite + TypeScript client for HireMe.

**Owner:** Nishtha

## Purpose
Candidate- and recruiter-facing UI: job search & filtering, resume builder, application tracking dashboard, real-time chat, and the recruiter dashboard that displays the Orchestrator's final recommendation for each candidate–job pair.

## Planned contents
- `src/pages/` — route-level views (job search, application tracking, recruiter dashboard, chat)
- `src/components/` — shared UI components
- `src/api/` — client for calling backend/Lambda function URLs
- `src/hooks/` — data-fetching and state hooks

## Status
Scaffolding only — implementation begins in a later phase (see `documentation/PRD.md`, Milestone 6).
